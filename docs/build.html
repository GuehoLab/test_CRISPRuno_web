Builds a reference index (.l2b + .mbw) from a FASTA file and lets you download it. Once saved, the files can be opened directly on the CRISPRuno page, so the index never has to be rebuilt.

Build index

For T2T (3.1 Gb) this takes about 1.5 h with one thread and about 1 h with two (less with more cores); keep the tab open meanwhile. The index stays in this browser's storage (OPFS) and can be downloaded below.

Save to folder writes name.l2b, name.mbw and name.build.json into the chosen folder in one go (Chrome/Edge). In other browsers, download the files one by one. After downloading you can delete the index from OPFS and still use it by opening the files on the CRISPRuno page. The same index also works with the CLI (minibwa map).
