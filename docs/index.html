CRISPRuno Web

처음1. 인덱스 만들기2. CRISPRuno

CRISPRuno(단방향 앵커 증폭 시퀀싱 분석, clementlab/CRISPRuno 0.1.22)를 브라우저 안에서 실행합니다. 정렬은 bowtie2 대신 minibwa(WebAssembly)로 하고, Cas-OFFinder 검색은 빠져 있습니다. 데이터는 이 컴퓨터 밖으로 나가지 않습니다.

1. 인덱스 만들기 reference FASTA → minibwa 인덱스(.l2b + .mbw). 한 번 만들어 저장해 두면 계속 다시 씁니다(인간 게놈 약 1–1.5시간). CLI minibwa index로 만든 파일도 그대로 씁니다. 2. CRISPRuno settings 파일 + FASTQ(R1/R2/UMI)로 prep → UMI → primer/adapter trimming → minibwa 정렬 → read 할당(translocation, large deletion/inversion, 분류) → CRISPResso 정량 → 요약을 단계별로 실행하고, SVG 그림이 든 HTML 리포트를 만듭니다.

환경

데스크톱 Chrome/Edge 권장. wasm64(Memory64)를 지원하면 4 GiB 한도 없이 더 빠른 설정으로 돌고, 아니면 wasm32로 돕니다. 인간 게놈은 RAM 16 GB 이상을 권장합니다.
