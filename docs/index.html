Home1. Build index2. CRISPRuno

Runs CRISPRuno (analysis of unidirectional anchored amplification sequencing, clementlab/CRISPRuno 0.1.22) inside the browser. Reads are aligned with minibwa (WebAssembly) instead of bowtie2, and the Cas-OFFinder search is not included. Your data never leaves this computer.

1. Build index Reference FASTA → minibwa index (.l2b + .mbw). Build and save it once, then reuse it (about 1–1.5 h for a human genome). Index files made with the CLI minibwa index work as well. 2. CRISPRuno From a settings file + FASTQ (R1/R2/UMI), runs prep → UMI → primer/adapter trimming → minibwa alignment → read assignment (translocations, large deletions/inversions, classification) → CRISPResso quantification → summary step by step, and builds an HTML report with SVG figures.

Environment

Desktop Chrome/Edge recommended. With wasm64 (Memory64) support the tool runs without the 4 GiB limit and with faster settings; otherwise it falls back to wasm32. For a human genome, 16 GB of RAM or more is recommended.
