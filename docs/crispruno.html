CRISPRuno Web

Home1. Build index2. CRISPRuno

Runs the CRISPRuno 0.1.22 (clementlab) analysis step by step in the browser: prep → UMI → primer/adapter trimming → minibwa alignment → read assignment → CRISPResso quantification → summary and report. Reads are aligned with minibwa instead of bowtie2, and the Cas-OFFinder search is not included. Output files are kept in a run folder in browser storage (OPFS) under the same names as the original.

Environment

No worker running

1. Run and settings

Uses the CRISPRuno settings file format as is (one key<TAB>value per line, # for comments). Command-line options can be written as lines in the same format (e.g. keep_intermediate True). Only file names are used from paths — fastq_r1/fastq_r2/fastq_umi/cut_region_annotation_file are looked up among the files selected below. genome/aligner_genome are ignored; the index and FASTA selected below are used instead.

Analysis options

CRISPRuno parameters. Changing a value here writes it into the settings text below (and a value set back to its default removes the line); editing the text updates these fields.

Settings text

Web-only options
Replaces bowtie2 --very-sensitive-local. -b MD is added automatically (the MD tag gives the matched length at each read end). The default lowers the minimum score so that short primer-trimmed reads (from 30 bp) still align (-s 20 -m 20) and lowers the end bonus so that mismatches at read ends are soft-clipped as in bowtie2 local mode (--end-bonus=5; minibwa default 10; an option added to this app's minibwa).
Aligns the primer and guide sequences as reads, replacing bowtie2 --end-to-end -c (set so that 20 bp sequences align).

2. Input files

Used for the origin sequence, the homology search (±30 bp) and CRISPResso amplicons (instead of samtools faidx). Selecting the .fai as well saves indexing time. If left empty, sequences are read from the index's .l2b (IUPAC codes become N).

StepOriginal (CRISPRunoCore.py)Status

Each step reads the files the previous steps left in the run folder (like the original's reuse of existing files), so a single step can be re-run on its own. Because the aligner is minibwa, read positions and MAPQ can differ slightly from bowtie2; given the same alignment (SAM), the outputs of all other steps are identical to the original.
